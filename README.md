# Repositorio de Ejemplos — GitHub Actions

Repositorio de demostración con ejemplos prácticos de GitHub Actions y buenas prácticas de documentación.

## Estructura del repositorio

```
.
├── .github/
│   └── workflows/
│       └── gh_action1.yml   # Workflow CI de ejemplo
├── gh_action_example2/
│   └── README.md            # Documentación del ejemplo
└── README.md                # Este archivo
```

## Ejemplos incluidos

| Carpeta | Descripción |
|---|---|
| `gh_action_example2/` | Ejemplo de workflow CI con jobs, steps y variables de entorno |

## Requisitos

- Cuenta en [GitHub](https://github.com)
- Repositorio con GitHub Actions habilitado (activo por defecto en repos públicos y privados)

## Uso rápido

1. Clona el repositorio:

```bash
git clone <repo-url>
```

2. Explora los workflows en `.github/workflows/` y adapta los ejemplos a tu proyecto.

3. Haz un push a la rama `dev` o abre un pull request para ver los workflows en acción.
